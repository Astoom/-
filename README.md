# 🎯 准星账号价格监控工具

## 🌟 功能介绍
本工具是一款专为目标网站打造的价格监控软件，主要功能包括：
1. **自动升序排序**：程序启动后自动点击价格表头，触发前端升序排序，确保监控的是升序数据
2. **实时价格监控**：循环刷新页面，提取并筛选低于设定阈值的价格
3. **微信通知提醒**：通过Server酱公众号推送监控结果，无需一直盯着电脑
4. **图形化控制**：支持开始/暂停/停止监控，实时日志输出，状态一目了然
5. **配置自动保存**：用户输入的SCKEY和价格阈值自动保存，下次启动无需重复输入

## 🚀 快速开始
### 1. 运行软件
直接双击 `zxsjz_monitor.exe` 即可启动，无需安装任何依赖。

### 2. 基础配置
- **价格阈值**：输入你想要监控的价格上限（例如：100.00 元）
- **Server酱SCKEY**（选填）：输入你的Server酱SCKEY，用于接收微信通知
- **刷新间隔**：每次刷新页面的间隔时间（建议 5-10 秒）
- **最大刷新次数**：最多刷新多少次后自动停止（默认 100 次）

### 3. 启动监控
点击「开始监控」按钮，程序会自动触发价格升序并开始监控。找到符合条件的价格后，会自动推送微信通知。

## 📱 微信通知配置（可选）
1. 访问 [Server酱官网](https://sct.ftqq.com/)，使用微信扫码登录
2. 在「发送消息」页面复制你的 `SCKEY`
3. 将 `SCKEY` 输入到软件的「Server酱SCKEY」输入框中
4. 确保已关注「Server酱」公众号，否则无法接收通知

## ⚠️ 注意事项
1. 本工具仅支持目标网站的价格监控，URL已固定，无法修改
2. 首次运行可能需要等待 Chrome 浏览器驱动自动下载，请保持网络畅通
3. 若出现「无法定位序数380」错误，请安装最新的 Windows 更新并修复系统文件
4. 建议将刷新间隔设置为 5 秒以上，避免被网站判定为爬虫
